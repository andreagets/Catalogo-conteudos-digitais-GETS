Meus recursos

Seu banco de referências. Os dados são salvos neste navegador e não são sincronizados entre dispositivos. Exporte um backup regularmente e antes de limpar os dados do navegador. O catálogo guarda metadados e links; os arquivos dos recursos permanecem onde você os publicou.
Como usar e preservar os cadastros

Cadastre o tipo, título, referência completa, forma de citação, data de produção, contexto de uso e link público de cada recurso. A referência pode seguir o padrão ABNT que você utiliza; a citação corresponde à forma curta para inserir em textos ou apresentações, como (Silva, 2026). Use “Exportar backup” para guardar um arquivo JSON com todos os registros. Para recuperar ou transferir o catálogo, abra este HTML em um navegador e importe o JSON: novos registros serão acrescentados e os existentes só serão atualizados quando a versão importada for mais recente. O CSV serve para consulta em planilhas, e não para restauração. Use sempre o mesmo navegador e endereço deste HTML para acessar seus dados locais. Em celulares, abra em um navegador com suporte a arquivos HTML; a prévia do gerenciador de arquivos pode não executar o sistema.
